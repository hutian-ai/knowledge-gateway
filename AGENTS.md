# Knowledge Gateway

- Own document originals, immutable version IDs, indexing state, source attribution and backend adapters.
- Host applications own people, members, conversations and business grants. Accept opaque resource IDs, never host roles or caller-selected backend credentials/paths.
- Providers own their indexes. Store originals before indexing, preserve unknown outcomes, never silently replay an unknown import.
- Keep operator bindings, tokens and evidence private. Preserve existing originals, IDs, versions, namespaces and indexes during explicit adoption.
- Follow parent no-added-tests and incremental-delivery rules. New source stays uncommitted; publication requires authorization.
